3. The service
FlightNerve provides a real-time flight data API. A single request can return a flight's live status, position, schedule, route and aircraft, plus airport, airspace, monitoring and webhook capabilities, in a structured JSON response. The endpoints, parameters and response formats are described in the API documentation , which forms part of these terms.
Flight data is aggregated from multiple upstream sources and derived signals. It is provided for informational and operational purposes. We work to keep it accurate and fresh, but we do not originate primary air-traffic-control data, and coverage or timeliness may vary by region, carrier and flight phase.
FlightNerve is a flight-operations data product. It is not a booking, ticketing or fares service, and it does not hold passenger or reservation records.
